# TCP Tuning-Simple Version
TCP调优简单版
```bash
bash <(curl -sL https://raw.githubusercontent.com/AiLi1337/TCP-Tuning-Simple-Version/main/TCP-Tuning-Simple-Version.sh)
```

📖 使用指南
运行脚本后，主菜单提供以下选项：
​
1.​智能调优 (推荐)​​
1. 自动检测并调优: 脚本自动 ping 测试延迟并推荐配置。
2. BDP计算调优: (占位功能，需手动输入带宽/延迟)。
3. 场景化调优: 根据您的用途（游戏、下载、服务器等）选择优化方案。
4. 微调功能: (占位功能，用于手动微调参数)。

2.​​手动调优​​: 直接输入特定的 TCP 读/写缓冲区大小（单位：MB）。

3.​​配置管理​​
查看当前配置: 显示当前生效的 TCP 参数。
配置对比: 将当前设置与系统默认值进行对比。
重置为默认: 恢复系统默认的 TCP 配置。
配置回滚: 选择并恢复到之前通过本脚本设置的任一历史配置。
备份管理: (占位功能，管理备份文件)。
​
4.​网络测试​​
延迟测试: 对 8.8.8.8进行 Ping 测试。
带宽测试: 提示使用 iperf3进行测试（需要额外设置服务器）。
综合测试: 结合延迟和下载速度测试。

5.​​系统诊断​​: 显示系统信息、内核版本、当前 TCP 算法、BBR 状态、内存和连接数等信息。

​​6.帮助信息​​: 显示本脚本的功能概述和使用建议。

⚙️ 工作原理
此脚本通过修改 Linux 内核运行时参数并持久化配置到 /etc/sysctl.conf和 /etc/sysctl.d/来实现优化。主要调整的参数包括：
net.ipv4.tcp_wmem: TCP socket 写缓冲区大小。
net.ipv4.tcp_rmem: TCP socket 读缓冲区大小。
net.ipv4.tcp_congestion_control: 拥塞控制算法（默认为 bbr）。
net.core.default_qdisc: 队列规则（默认为 fq）。
修改前脚本会自动备份原始配置，确保操作安全且可逆。
